# Licences of the tree files

Generated by `scripts/tree_licences.py` of the paper repository from `registers/tree_licences.csv`, which records for each source the licence its archive states, the evidence (URL and quotation) and the date it was checked. Do not edit by hand.

The catalogue's own work (the registers, the name layer, the code, the paper's generated files and the browser site) is under CC BY 4.0 (`LICENSE`). A tree file is the work of the study that published it, relabelled with the catalogue's tip identifiers and, for a reference tree, pruned to its group with one tip per species; each is redistributed under the licence of its source, listed below, and only where that licence allows redistribution. The changes made to every file are recorded in `standardized/tree_references.csv`, `registers/canonical_sources.csv` and `registers/canonical_source_prep.csv`.
