Francisco delegated these on 2026-10-07 with the instruction to decide each by the most objective
rule available. Each decision states the rule, so that it can be checked and reversed by rule
rather than by preference.

| D23 | Worked example (audit A05, A11) | A demonstration isolates the quantity it is about and reports every eligible case | Each eligible partition (absolute chronogram with enumerated molecular tips fewer than all tips) is fitted with rho = tips/described on the full and the molecular-pruned tree, and with rho = C0/described on the molecular-pruned tree (the misapplied named coverage). | D24 | Genus test and authority mismatch in C0 (audit A10) | A label is classified by the authority, not by its spelling; a numerator bound that depends on one authority is reported beside the alternative | (a) A capitalised token ending in a suprageneric suffix (-idae, -aceae, -oidea, -ales, -phyta, ...) is a genus when COL26.9 lists a genus of that name (Data/standardized/col269_suprageneric_genera.txt, 338 genera, written by `match_col.py --genera`). | D25 | C1b and calibration priors (audit A14) | An interval that reproduces the calibration prior on its own node does not bound a divergence time from data | `Data/calibration_register.csv` records, for every interval of a counted kind, the calibration the source placed on the focal node (two_sided, one_sided, none, not_checked) with its source file and quotation. Where it is two-sided, the interval reproduces the prior, and is excluded from C1b, when at least 90% of its width lies inside the prior's 95% range and the data did not halve that width (interval width / prior width >= 0.5). The prior range is the effective prior of a sample-from-prior run of the source's own input file where one was run (Cephalopods: BEAST 2.7.7, 236.66-251.20 Ma), else the calibration as specified. One-sided, absent or unchecked calibrations do not exclude. Cephalopods and Sponges are excluded; C1b with them counted is in sensitivities.c1b_calibration_fixed. |
| D26 | Worked example: what the rho contrast shows (audit A15) | A demonstration states the algebra that produces its result, and an interval is calibrated for the null it tests | The rung contrast on one tree is reported as the identity it is: the likelihood depends on lambda and rho only through lambda*rho and r (Stadler 2009), so where mu stays interior lambda scales by rho_tips/rho_C0 with r and the log-likelihood unchanged; where the misapplied rho forces mu = 0 the pair is classified 'boundary' and the likelihood-ratio statistic is reported (rho_C0 rejected beyond qchisq(0.95, 1)). Interval cutoffs: D30. rho = tips/described is labelled conditional on uniform sampling, and each molecular tree is also fitted with per-family sampling fractions (COL26.9 accepted species per family; FitzJohn, Maddison & Otto 2009). Cusimano & Renner 2010 and Hoehna et al. 2011 are cited for the rho-epsilon confounding. |
| D27 | Worked example: the mismatched fraction (round-1 readers R1-03, R1-11, R1-13) | A demonstration uses the error a user can make with the files they download, and a test is calibrated for the constraint it tests | The mismatched fit supplies the full tree's sampling fraction (its tips over described species, the fraction quoted for the downloaded tree) to the tree pruned to its molecular tips (`rho_convention` full_misapplied), replacing named coverage, which no source reports and which is lowered by unresolved and merged labels. The mismatched fit is the matching fit under the inequality mu >= 0 after rescaling, so the likelihood-ratio statistic is referred to the 50:50 chi2(0):chi2(1) mixture (Self & Liang 1987), critical value qchisq(0.90, 1) = 2.71. Family and uniform sampling are reported side by side (D30). |
| D28 | Squamates interval and what each study dated (R1-09, R1-10) | A deposited tree set is read when it can be obtained; a classification describes the study, not only the redistributed file | The Tonini et al. 2016 posterior (10 x 1,000 trees, VertLife bucket, the files listed on Dryad doi:10.5061/dryad.db005) is read as a posterior_sample like Amphibians; its crown calibration is not_checked (Dryad methods file returned 401), so by D25 it is not excluded. `Data/dating_deposit_checks.csv` gains `study_dating` (absolute_deposited, absolute_deposited_fewer_tips, absolute_not_deposited, absolute_not_read, relative_only, not_dated), shown in Table 1. `Data/molecular_only_trees.csv` records, for every group whose tree has taxonomically placed tips, the tree of molecular species its source distributes. | D29 | Sharks interval and the loss accounting (round-2 readers R2-06, R2-15, R2-16) | An interval that returns its calibration prior is set by a calibration whether a test or the dating design shows it; the losses between levels are counted in the same convention as the levels | A tree set dated under root ages drawn from the calibration prior (`calibration_prior_sample`, Sharks) returns the prior at the crown by construction, so its `c1b_exclusion` is `prior_reproduced` (set by a calibration), not `kind`. | D30 | Worked example: which comparisons are reported (round 3) | Report only comparisons that a valid test or criterion supports, and calibrate every interval for the values it covers | (a) Family and uniform sampling are not compared by log-likelihood: the two likelihoods carry different probabilities of sampling the same tips (the product of the per-tip family fractions against rho^n), terms free of the rates, and the family fractions are computed from the tips themselves, so their difference is not a model comparison. Table 3 reports epsilon and r of the two fits side by side. (b) The likelihood-ratio test of the full tree's fraction stands: in the parameters of the matching fit, the fit at rho_full is the same model restricted to epsilon >= 1 - rho_tips/rho_full, an edge inside (0, 1), so at the least favourable point the statistic follows the equal chi2(0):chi2(1) mixture (Self & Liang 1987), critical value qchisq(0.90, 1) = 2.71 at the 5% level; the text states the null, the restriction and the distribution, and verify_atlas.py checks the nesting (boundary iff the matching epsilon is below the edge; interior pairs map by 1 - eps' = (1 - eps) rho_full/rho_tips). (c) Every profile interval uses qchisq(0.95, 1)/2. The one-sided cutoff qchisq(0.90, 1)/2 applied only where the estimate is 0 chose the interval from the data and covers an interior epsilon with probability 0.90; where the estimate is 0 the interval is now [0, upper] at the ordinary cutoff. verify_atlas.py recomputes the log-likelihood of every uniform fit up to 15,000 tips with an independent implementation and checks the statistic at each interval end. |
